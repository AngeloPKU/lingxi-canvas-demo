# 灵犀 Canvas 交互原型

灵犀（办公 Agent）Canvas 能力的静态交互 Demo：对话中产出文档 / 演示 / 表格，点击卡片在右侧分屏打开内嵌编辑环境，支持在文件内划选局部内容并发起 AI 编辑。

## 打开方式

直接访问在线地址（GitHub Pages）：

https://angelopku.github.io/lingxi-canvas-demo/

或本地打开 `index.html`（零依赖、无构建，双击即可）。

## 能力清单

- 对话产出 docx / pptx / xlsx 文档卡片，点击在右侧分屏打开；多标签切换、关闭、全屏
- 三组件编辑视图：文字纸张、演示（缩略图切页 + 演讲者备注）、表格（公式栏 + 全屏网格 + 工作表页签），均支持基本编辑
- 文件内划选（文字拖选 / 表格拖拽框选）出现悬浮工具栏，首位为「AI 编辑」
- AI 编辑浮层：发送（单条直发）或添加（选区标签进入主输入框混排）
- 主输入框选区标签混排：标签原子化、文字与标签任意穿插、hover 查看完整选区
- 带选区发送后的编辑中反馈：文件侧黄条提示、更新预览 loading、多文件状态隔离
- 草稿期切换文件的确认保护

## 说明

本 Demo 为交互示意：文档内容为 mock，AI 处理与文件更新以固定时长模拟，不含真实模型与真实文件写入。
